ロングケープの定理とは？

「上手い人と同じ感度にしたのに、なぜか自分には合わない」——その原因は、腕の長さも関節の可動域も、使っているマウスの重さも人によって違うからです。ロングケープの定理は、身長・腕の太さ・手先の器用さ・マウス重量・エイムの支点という身体的および環境的なパラメータから逆算して、その人にとって理論上もっとも制御しやすいインゲーム感度を求める無料ツールです。登録なしでご利用いただけます。

詳しい解説を読む（eDPI・身体特性・タイトル別の違い・使い方）

eDPI と cm/360 ― 感度を比較する共通単位

ゲーム内の感度数値そのものにはほとんど意味がありません。VALORANT の 0.35 と Apex Legends の 0.35 はまったく違う速さになるためです。比較可能にするのが eDPI（＝ DPI × インゲーム感度）と、360 度振り向くのに必要なマウスの移動距離を表す cm/360 です。エイムは結局のところ腕と手首の運動なので、最終的にはこの移動距離が身体に合っているかどうかがすべてを決めます。本ツールが身体パラメータを尋ねるのは、この動作量を身体側から逆算するためです。

なぜ身体的特徴で最適な感度が変わるのか

もっとも影響が大きいのはエイムの支点です。手首エイムは可動範囲が狭いため短い距離で振り向ける速い感度が必要で、肩エイムは大きく腕を動かせるため低感度でも十分に振り向けます。身長は腕の長さと相関し、腕が長いほど同じ回転角に対する移動距離が伸びます。腕の太さは動き出しと停止の慣性に、マウス重量は初速の出しやすさに直結します。手先の器用さは、指先での微調整がどれだけ利くかを表します。

ゲームタイトルごとに数値が違う理由

各タイトルは、インゲーム感度の「1」が意味する角度がそれぞれ異なります。VALORANT / CS2 は 0.1 刻みの微細な調整が効く基準系、Overwatch 2 や CoD は 1〜100 のスケール、Fortnite は％表示、PUBG は対数的なスケールです。本ツールはまず身体から導かれる基準 eDPI を求め、そこにタイトルごとの単位変換とプレイスタイル補正を掛けます。そのため同じ身体パラメータでも、各タイトルで体感的に等価な感度が表示されます。

診断結果を実際に使うときの手順

現在の感度と診断結果が大きく離れている場合、一度に乗り換えると数日間はむしろ成績が落ちます。まず現在値と目標値の中間から始め、1 週間ごとに寄せていくのが安全です。DPI は 800 のまま固定し、インゲーム感度側で調整するのが基本になります。感度変更の直後は必ず違和感が出ますが、それが「合っていない」のか「慣れていない」のかは最低 3 日ほど使わなければ判別できません。しっくり来た値は感度メモに保存しておくと、迷走したときに戻る場所ができます。

データが増えるほど精度が上がる仕組み

本ツールの補正係数は固定値ではありません。利用者が入力した「実際に使っている感度」を統計的に集計し、身体パラメータとの関係を回帰分析することで定期的に更新されます。少数の極端なデータに振り回されないよう、1 回の更新幅を最大 ±10% に制限し、タイトルごとの外れ値の自動除外、ボツ評価データの学習除外、同一利用者の重複除去、本ツール自身の出力の学習除外といった安全装置を設けています。診断時の「現在のインゲーム感度」の入力は任意ですが、ご協力いただくほど全利用者にとっての精度が上がります。
